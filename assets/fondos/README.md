# Fondos del resumen semanal

Fotos de fondo de las placas del carrusel, una carpeta por categoría. El script las recorta a
1080×1350 (centro) y les aplica el lavado verde de marca, así que no hace falta editarlas.

Cada categoría puede tener todas las fotos que quieras: rotan por semana (la semana ISO del viernes
del resumen) y nunca se repite una foto dentro del mismo carrusel. Para sumar una, agregala a la
carpeta con el siguiente número (`siembra-05.jpg`).

| carpeta | dónde se usa | fotos |
| --- | --- | --- |
| `campo/` | tapa y cierre; respaldo de cualquier categoría vacía | 4 |
| `granos/` | placa de precios | 4 |
| `siembra/` | temas con etiqueta Campaña / Siembra / Cultivos | 4 |
| `cosecha/` | temas con etiqueta Cosecha | 3 |
| `puerto/` | temas con etiqueta Exportaciones / Puertos / Embarques / Molienda / Industria | falta |
| `camiones/` | temas con etiqueta Comercialización / Ventas / Logística / Fletes | falta |
| `pulverizacion/` | temas con etiqueta Agroquímicos / Insumos | falta |

Sirve `.jpg`, `.jpeg`, `.png` o `.webp`. Lado corto de al menos 1350 px (vertical o cuadrada
ideal; una horizontal sirve, pero se recortan los costados).
Criterio de marca: luz cálida (hora dorada), nada frío ni en blanco y negro, sin texto, logos ni
marcas visibles, sin caras reconocibles.
