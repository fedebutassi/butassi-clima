# Fondos del resumen semanal

Fotos de fondo de las placas del carrusel. El script las recorta a 1080×1350 (centro) y les aplica
el lavado verde de marca, así que no hace falta editarlas.

| archivo | dónde se usa |
| --- | --- |
| `campo.jpg` | tapa, y respaldo de cualquier fondo que falte (hoy: la foto del hero de la web) |
| `cierre.jpg` | placa de cierre |
| `granos.jpg` | placa de precios |
| `siembra.jpg` | temas con etiqueta Campaña / Siembra / Cultivos |
| `cosecha.jpg` | temas con etiqueta Cosecha |
| `puerto.jpg` | temas con etiqueta Exportaciones / Puertos / Embarques / Molienda / Industria |
| `camiones.jpg` | temas con etiqueta Comercialización / Ventas / Logística / Fletes |
| `pulverizacion.jpg` | temas con etiqueta Agroquímicos / Insumos |

Sirve `.jpg`, `.jpeg`, `.png` o `.webp`. Mínimo recomendado: 1080 px de ancho y 1350 de alto
(vertical o cuadrada); una horizontal también sirve, pero se recorta mucho de los costados.
Criterio de marca: luz cálida (hora dorada), nada frío ni en blanco y negro, sin texto, logos ni
marcas visibles, sin caras reconocibles.
